# Jaelin 赵佳琳｜AI 产品经理个人网站

这是 Jaelin 赵佳琳的个人作品集网站。当前版本采用浅色未来科技视觉，以“鼠标即光源”为核心交互概念，集中展示 AI 产品项目、工作经历与产品能力。

## 核心内容

- Westlake Financial 贷款业务智能客服
- ShopLine Sidekick 商家后台 AI Copilot
- 数据中台 AI 测试助手
- AI 产品经历与工作方法
- GitHub 代码作品入口

## 视觉与交互

- 浅色空间棱镜与毛玻璃界面
- 鼠标光源、粒子漩涡与光轨拖尾
- 项目卡片 3D 倾斜和表面高光
- 滚动入场、进度反馈与动态技能标签
- 桌面、平板和手机响应式适配

## 技术实现

- 单文件 `index.html`
- 原生 HTML / CSS / JavaScript
- 所有视觉资产、样式与脚本内联
- 无构建步骤，无第三方运行依赖
- 支持 `prefers-reduced-motion` 与移动端性能降级

## 本地运行

直接双击 `index.html`，或在仓库目录启动任意静态文件服务。

## 项目结构

```text
index.html  完整网站（包含全部 CSS、JavaScript 与内联视觉资产）
```
